## About

I build tools that make application security work faster without making it careless. Right now that's **VIPER** — a bounded, evidence-first bug-bounty research platform, submitted to **OpenAI Build Week 2026**, where Codex and GPT-5.6 were used as a real adversarial engineering partner: tracing callers, capturing real network traffic to diagnose broken routes, writing regressions, and reviewing design decisions.
